# Sergio Brancato — Portfolio

**Live Website:** [sergiobrancato.github.io](https://sergiobrancato.github.io)

A personal portfolio built to show how I bridge **software engineering** (MSc in Software Design, IT University of Copenhagen) with **human-centered communication** (BSc in Communication). It is designed for recruiters, engineering teams, and research collaborators looking for someone who pairs clean system architecture with clarity, usability, and cross-functional teamwork.

## What's Inside

- **Hero:** Full-viewport landing section with kinetic typewriter roles and dark/light mode switching (dark by default).
- **About:** My background, approach to building reliable software, European mobility, and target sectors.
- **Skills & Stack:** Categorized capabilities across programming languages, data visualization, backend/desktop development, security, and product design.
- **Experience & Education:** A scannable timeline of my academic path, research development work, and customer-facing roles.
- **Interactive Portfolio:** Filterable project cards that open into expandable case-study modals with image galleries, project breakdowns, and external links.
- **Contact:** One-click email copy, downloadable CV, and direct social/code links.

## Tech & Structure

- **Built with:** Next.js (App Router, Static Export), TypeScript, Tailwind CSS, and Framer Motion.
- **Content-Driven:** All text, timeline entries, and portfolio projects live in `src/content/`, keeping UI components completely separate from content updates.
- **Automated Deployment:** Pushes to `main` automatically build and deploy to GitHub Pages via GitHub Actions.
